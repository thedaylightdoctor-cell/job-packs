# Daylight Doctor Job Packs

A phone app for The Daylight Doctor site surveys. Fill in the customer, site and windows, add photos, then make a branded installer job pack PDF and share it on WhatsApp or by email.

- Jobs and photos are saved on the phone only. Nothing is uploaded to this site.
- Add it to your home screen and it works with no signal.
- Job packs never include prices.

To change the app, edit `src/app.html` and run `python3 src/build.py`, which writes `index.html`, `manifest.webmanifest` and `sw.js`.
